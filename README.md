# Habit Tracker App - FunDev Competition

Aplikasi web pencatat dan pengingat kebiasaan harian (*habit tracker*) untuk membantu pengguna membangun rutinitas positif secara konsisten.

## 🚀 Fitur Utama
- Tambah, pantau, dan kelola daftar kebiasaan harian.
- Antarmuka interaktif dan responsif berbasis React & Tailwind CSS.
- Visualisasi progres pencapaian kebiasaan pengguna.

## 🛠️ Tech Stack
- **Frontend Framework:** React + Vite
- **Styling:** Tailwind CSS

## ⚙️ Cara Menjalankan Project (Installation)
1. Pastikan **Node.js** sudah terinstal di komputer Anda.
2. Clone atau download repository ini.
3. Buka terminal pada direktori project, lalu instal dependensi:
   ```bash
   npm install
